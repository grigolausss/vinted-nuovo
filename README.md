# Vinted Listing Copilot (macOS Edition) 🚀

Benvenuto in **Vinted Listing Copilot**, l'app definitiva per scalare le tue vendite su Vinted con un'esperienza nativa in stile Apple.

## 📋 Prerequisiti

Per far girare l'app sul tuo Mac, assicurati di avere installato:
- **Node.js** (versione 18 o superiore)
- **npm** (incluso con Node.js)

## 🚀 Come avviare l'app

Segui questi semplici passaggi dal tuo terminale:

1. **Installa le dipendenze:**
   ```bash
   npm install
   ```

2. **Avvia il server di sviluppo:**
   ```bash
   npm run dev
   ```

3. **Apri l'app:**
   Una volta avviato, il terminale ti mostrerà un indirizzo (solitamente `http://localhost:5173`). Copia e incolla questo indirizzo nel tuo browser (Safari, Chrome o Edge).

## ⌨️ Scorciatoie Mac (Keyboard-First)

L'app è velocissima da usare grazie alle scorciatoie integrate:
- **⌘ + 1**: Vai alla Tab "Genera"
- **⌘ + 2**: Vai alla Tab "Archivio"
- **⌘ + Enter**: Genera istantaneamente l'inserzione
- **⌘ + N**: Inizia un nuovo articolo (reset veloce)
- **⌘ + K**: Cerca velocemente nel tuo Archivio

## ✨ Funzionalità Incluse
- **Ottimizzazione SEO:** Genera titoli perfetti per scalare i risultati di ricerca.
- **Descrizioni Umane:** Testi pronti all'uso, amichevoli e professionali.
- **Tracker Intelligente:** L'app ti avvisa dopo 4, 10 o 15 giorni se un articolo non è stato venduto, suggerendoti la strategia migliore (ribasso o relist).
- **Zero Allucinazioni:** Il sistema usa solo le informazioni che inserisci tu.
